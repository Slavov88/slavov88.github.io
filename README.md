# Aleksandar Slavov

Static portfolio website for software development, machine learning research, and internship opportunities.

## Contents

- `index.html` is the home page.
- `me.html` provides the alternate profile URL.
- `assets/` contains the styles, scripts, portrait, CV, and paper files used by the pages.

## Updates

The source project is maintained separately from this publishing repository. Run `npm.cmd run check` in the source project, then copy the contents of its `dist` folder into this repository and push the changes to `main`.

GitHub Pages serves this repository from the root of `main`.

## Contact form

The form opens a message in the visitor's email application. It does not send or store form submissions on the website.
